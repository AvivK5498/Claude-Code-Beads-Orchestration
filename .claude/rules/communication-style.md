# Стиль общения

## Главное правило

Пиши на простом русском. Цель — чтобы человек без программистского бэкграунда понял с первого раза. Никаких англицизмов, калькированного сленга или транслитераций английских слов, если есть короткий русский эквивалент.

## Триггер: когда правило срабатывает

Перед отправкой **каждого** ответа пользователю. Применяется ко всем русским текстам — сообщения в чате, описания задач, комментарии в коде, сообщения коммитов.

## Что делать

1. **Найти в тексте слова-маркеры и переписать.** Частые случаи:
   - «робастный / робастность» → «надёжный / устойчивый»
   - «итерация» (в смысле «попытка/проход») → «попытка», «проход», «шаг»
   - «реджект / реджектится» → «отклоняется / отказ»
   - «коллбэк» → «обратный вызов»
   - «фикс» → «исправление»
   - «майнтейнить» → «поддерживать»
   - «эдж-кейс» → «крайний случай»
   - «trade-off» → «компромисс»
   - «diminishing return» → «убывающая отдача»
   - «overhead» → «накладные расходы»

2. **Любая транслитерация английского термина кириллицей — тоже под правило**, если есть короткий русский аналог:
   - «тенант» → «арендатор»
   - «энтити» → «сущность»
   - «инстанс» → «экземпляр»
   - «пейлоад» → «полезная нагрузка»
   - «митап» → «встреча»
   - «челлендж» → «сложная задача»
   - «дедлайн» → «срок»
   - «деплой» → «развёртывание»
   - «фича» → «возможность / функция»
   - «ассерт» → «проверка»

3. **Латиница в русском тексте — заменить или объяснить.** Исключения, которые остаются как есть: имена файлов, команды, фрагменты кода, пути, git-сущности, имена собственные, устоявшиеся технические термины (`git`, `npm`, `PR`, `API`).

4. **Если короткого русского аналога нет** — использовать английский термин и объяснить в скобках при первом упоминании. Дальше — русский вариант или объяснённый английский.

5. **Укоренилось — оставить:** «коммит» (в контексте git), «рефакторинг», «бэкенд», «фронтенд», «дебаггер».

## Запреты

- Извиняться или ставить пометки «заменил X на Y» — переписывать молча
- Использовать жаргон, когда есть простое русское слово
- Использовать английский термин без объяснения, если у него есть русский аналог
- Воспринимать список маркеров как закрытый — это примеры, правило шире: любая транслитерация англицизма попадает под него
