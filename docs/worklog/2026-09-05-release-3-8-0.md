# 2026-09-05 — выпуск v3.8.0

Первый выпуск после того, как README догнал код. Тег `v3.7.0` стоял на
коммите, где история выпусков в README обрывалась на v3.3.0; разделы v3.4–v3.7
были дописаны задним числом уже после тега. Поэтому «Не выпущено» на момент
выкатки описывал не всё, что накопилось: тридцать пять коммитов против пяти
пунктов.

## Что попало в раздел дополнительно

Сверка `git log v3.7.0..HEAD` с текстом раздела дала четыре изменения, заметных
человеку, но не описанных:

- `CLAUDE.md` на выбранном языке (был только английский шаблон);

- `--force` перезаписывал правленое правило без копии;
- путь не того вида обрывал всю установку, а не один файл.

Остальные коммиты после тега — рефакторинг установщика, тесты и журналы — в
README не выносятся: снаружи их не видно.

## Что проверять первым, если сломается

- **npm показывает прежнюю версию сразу после выкатки** — это не поломка.
  Реестр отвечает «Your package is being processed and may take a few minutes
  to become available», `dist-tags` обновляется с задержкой. Смотреть на строку
  `+ claude-protocol@<версия>` в логе шага «Publish to npm», а не на
  `npm view`.
- **`npm warn publish "bin[claude-protocol]" script name scripts/cli.js was
  invalid and removed`** — тоже не поломка: npm срезает ведущее `./` в пути.
  В опубликованном пакете `bin` на месте, проверяется через
  `npm view claude-protocol@<версия> bin`.
- **Версия в четырёх местах** (`package.json`, `.claude-plugin/plugin.json`,
  два поля в `.claude-plugin/marketplace.json`) — держит тест
  `TestPluginManifests::test_one_version_in_three_places`.
